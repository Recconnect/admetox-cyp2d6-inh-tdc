# TDC Submission Metadata

## Benchmark

- Benchmark group: ADMET Group
- Endpoint: `CYP2D6_Veith` (CYP2D6 inhibition)
- Task: binary classification
- Metric: AUPRC
- Split: official TDC scaffold split (10,504 train_val / 2,626 test)

## Model

- Name: ADMETox MapLight + Frozen GIN leg
- Formula: `CatBoost(MapLight 2580d + 4 x 300d frozen Hu2020 GIN embeddings)`, 15 seeds; run = mean of 3 disjoint seeds
- MapLight features: Morgan r2 count 1024 + Avalon count 1024 + ErG 315 + RDKit2D 217
- Frozen GIN: contextpred / masking / infomax / edgepred, 300-d mean-pooled, weights committed in `assets/gin_weights/`
- CatBoost: 800 iters, lr 0.1, subsample 0.6, `SqrtBalanced`, seeds 1-15
- Independent runs: 5
- Source: https://github.com/Recconnect/admetox-cyp2d6-inh-tdc

## Result

Generated by `python run_cyp2d6_inh.py` (reproduce mode) and copied from `output/cyp2d6_inh_results.json`.

- Individual AUPRCs: `0.8201, 0.8206, 0.8233, 0.8202, 0.8197`
- Mean / std: `0.8208 +/- 0.0013`
- TDC `evaluate_many`: `0.821 +/- 0.001` (TDC rounds mean/std to 3 decimals)
- Current TDC leader: `0.790 +/- 0.001` (MapLight + GNN)
- Gap: `+0.0308` — **BEATS SOTA**

## Reproduction

```bash
python install.py
python run_cyp2d6_inh.py
```

The default command reproduces `output/cyp2d6_inh_results.json` deterministically from the committed per-seed predictions (`assets/cyp2d6_inh_legs.npz`). Full end-to-end retraining of every model is available via `python run_cyp2d6_inh.py --mode train`.
